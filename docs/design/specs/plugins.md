# 第三方插件、插件市场和资源包（定稿，2026-10-21）

用户确认：6 件事都按推荐。方案页和可点原型只有用户能打开。插件作者看的接口约定在 `docs/PLUGINS.md`。

---

## 0. 已定的规则

- **还是一个 exe。** 每个版本都发 `wakuwaku-v<版本>-windows-x64.exe` 和它的 `.sha256`，永远保留。老版本只认这两个文件来更新，新 exe 也一直认 `--after-update`。
- **插件和资源包放在 exe 旁边的数据文件夹里**，用到时下载。更新只换 exe，这些不动。
  - 插件：`wakuwaku-data\plugins\<id>\`
  - 宠物包：`wakuwaku-data\pets\<id>\`，和现有的宠物放一起
  - 壁纸包：`wakuwaku-data\wallpapers\<id>\`
- **三档：**
  1. 只交数据，用内置卡片显示。主推。
  2. 在沙盒里自绘界面。①② 是同一种插件，代码都在沙盒里跑，只是交出来的东西不同。
  3. 外部程序通过本地接口 `POST /widget` 推内容。只写进文档，市场不收。
- **市场不收带可执行程序的插件**，长期规则。从文件安装也一样，包里有程序就拒装。

## 1. 入口

- **「插件」页最上面**一行「获取更多 ›」，副标题「插件、宠物和壁纸，都经过审核，不含可执行程序」。点进去是「插件」页里的二级页（左上 ‹ 返回，路径「插件 › 获取更多」）。不在设置顶部加新标签，也不开新窗口。
- **三个直达入口**，打开同一个市场，已按类别筛好：
  - 小工具库底部的「获取更多…」：小工具类。按钮原本就在，点了只说「还没有」。
  - 外观页「她」那组的宠物里，最后一格「获取更多宠物…」：宠物类。
  - 外观页「壁纸」那组最后一行「获取更多壁纸…」：壁纸类。

## 2. 市场（二级页）

- 搜索框，类别：全部 / 小工具 / 宠物 / 壁纸。
- 每行：图标块、名字、@作者、类别，自绘界面的标「自绘界面」，一句话介绍，右边「安装」。装过的写「已安装」，有新版写「更新」。
- 页尾一行小字：「市场里的都经过审核，不含可执行程序。」
- **详情**（点一行进去，路径「获取更多 › 名字」）：
  - 头部：图标块、名字、@作者 · 版本 · 大小 · 类别，「已审核」绿标，右边按钮：安装 / 添加小工具… / 去「外观」里选。
  - 它的卡片样子（小档、中档），没截图就不显示这块。
  - 介绍。
  - 「它能做的」：联网访问哪些网站、读 agent 会话、读硬件读数、提醒你；最后一行灰字「读写你的文件、运行程序、看别的插件的数据：都做不到」。资源包写「只有图片，没有代码」。
- **安装**：要了敏感权限（agents、hardware、notify）的，先弹面板内的确认层「安装「X」？它会：…」，按钮「取消 / 安装」。只联网的直接装，联网的网站已写在详情里。装好提示「装好了「X」· 用「添加小工具…」放到哪里」，资源包是「· 在「外观」里选」。
- **装好不等于放上**：沿用「放了就是开」。装好的小工具出现在「插件」页，写「没放」和「添加小工具…」；在小工具库里排在最前，标「新」，直到放上一次。

## 3. 「插件」页

- 「获取更多 ›」下面，有更新又关了自动更新时，加一条「N 个插件有更新 · 全部更新」。
- 「插件和小工具」一组里，第三方插件和内置插件排在一起：
  - 状态行：「运行中 · @作者 · v版本」。从文件装的加琥珀色「未经审核」标。
  - 「设置」按 manifest 的 `settings` 自动画，和内置插件的设置一个样子。
  - 点名字进详情。详情里有「卸载」，先确认「卸载「X」？它存的数据也一起删掉。」，按钮「取消 / 卸载」。
  - 无响应被停用的：「无响应，已停用 · 几点起 3 次没回答」，右边「重新启用」。
- 「资源包」一组（有才显示）：名字、类别 · @作者 · 大小，右边「在「外观」里选」。
- 「显示」那组加两行：
  - 「插件自动更新」开关，默认开，说明「每天和 Wakuwaku 一起看一次；要更多权限时先问你」。
  - 「从文件安装… ›」，说明「别人发给你的 .zip，或你自己写的插件」。
- **从文件安装**：系统的打开对话框，只选 .zip。
  - 能装的：确认层「安装「X」？」，琥珀色说明「未经审核：没人看过它的代码。它和市场里的插件一样跑在沙盒里，读不了你的文件，也运行不了程序。」，下面列出它会做的事，按钮「取消 / 仍然安装」。
  - 包里有程序的：「装不了 X.zip」，琥珀色「包里有可执行程序：helper.exe。Wakuwaku 的插件不能带程序。」，下面一句指向外部程序的文档，按钮「知道了」。
  - 同一个 id 已经装了：当作更新，说明里写「替换已装的 1.2.0，设置和数据保留」。

## 4. 自绘界面（第 ② 档）出现在哪

- **只在**桌面上的中、大档卡片，和胶囊里展开的整宽卡片。卡片的玻璃、圆角、悬停按钮、右键菜单都是她画的，插件只画卡片里面。
- 任务栏、胶囊里的行、收起的胶囊、她身上：一律用插件交的数据画成标准样子。所以每个插件都至少要交数据。
- 没人在电脑前、桌面被盖住、或系统关了动画时，自绘界面停下，换回用数据画的标准样子。

## 5. 更新

- 默认自动更新，和 Wakuwaku 自己的更新检查一起每天一次，走「网络代理」设置。
- 新版本要更多权限：不自动更新。「插件」页那条「有更新」点「全部更新」时，先弹确认层，列出新增的权限。
- 关了自动更新：只显示「N 个插件有更新 · 全部更新」。

## 6. 审核（市场仓库）

- 市场是一个公开仓库，作者提 PR。仓库还没建，等用户来建。工具和说明在本仓库的 `tools/market/`。
- 机器先查，过了用户再看一眼、合并：
  - 格式；
  - 文件类型白名单，并按文件头查可执行文件（不只看扩展名）；
  - 体积：插件 ≤ 5 MB，资源包 ≤ 50 MB；
  - 可能的话，在无头浏览器里跑 60 秒看 CPU。
- 合并后自动生成目录 `index.json`，GitHub 和 Gitee 各一份。

## 7. 她本人

- 插件不能让她说话、做动作。
- 插件可以申请 notify 权限，走现有的冒头提醒（nudge）：每个最多一分钟一次，她在等你批准时不打扰，跟「插件可以叫开灵动岛」开关走。

## 8. 性能护栏

- 放上去才运行。
- 没人在电脑前时，`waku.every` 的间隔放慢到三倍。
- 看门狗：每 5 秒问一声，3 秒不答就重载；再不答就停用，写在「插件」页上。所有插件共用一个进程，同时不答时，一个一个重启找出是谁。
- 任务栏上不放第三方自绘的东西。

## 9. 分期

1. 运行环境 + 第 ① 档 + 从文件安装，附开发文档、示例插件。
2. 第 ② 档自绘界面 + 看门狗。
3. 市场：目录、二级页、详情、权限确认、自动更新、小工具库的「获取更多…」；`tools/market/` 的审核和出目录工具。
4. 资源包：宠物、壁纸的安装和外观页入口。

无人值守时都做在 `plugins` 分支上，不合进 dev，等用户回来验收。
